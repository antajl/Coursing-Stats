# Security Policy

## Supported Versions

Безопасность платформы поддерживается для актуальной версии кодовой базы в ветке `main` и сервисов продакшена:

| Domain | Supported |
| :--- | :--- |
| Public Website (https://coursing-stats.ru) | Yes |
| Telegram Bot (@coursing_stats_bot) | Yes |
| Static CDN API (/data/v1/) | Yes |

---

## Reporting a Vulnerability

Если вы обнаружили потенциальную уязвимость безопасности или проблему с защитой данных:

1. **Не создавайте публичный Issue на GitHub.**
2. Направьте подробный отчет на почту мейнтейнера: **antajl@yandex.ru** с темой `[Security] CoursingStats Vulnerability`.
3. Опишите шаги для воспроизведения проблемы, потенциальное воздействие и возможные рекомендации по исправлению.

Мы подтвердим получение сообщения в течение 48 часов и предоставим информацию о сроках выпуска исправления.

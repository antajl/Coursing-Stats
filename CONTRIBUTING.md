# Руководство по участию в проекте (Contributing Guidelines)

Мы приветствуем вклад в развитие кинологической платформы CoursingStats. Проект ориентирован на точность спортивной и выставочной статистики, высокую производительность и строгий минималистичный дизайн.

---

## 1. Архитектурные принципы

- **Zero-Backend CDN:** Публичный сайт не использует базу данных во время выполнения. Все данные отдаются в виде предрассчитанных и сжатых JSON-пакетов через CDN Yandex Object Storage (`/data/v1/`).
- **Три изолированных домена:** Правила соревнований (курсинг/рейсинг), выставок РКФ и замеров спринта в Донино строго разделены и никогда не смешиваются.
- **Old Money Design System:** В интерфейсе, документации и коммитах действует полный запрет на использование эмодзи. Используются контурные SVG-иконки Lucide и палитра теплых песочных и терракотовых оттенков.

---

## 2. Разработка и окружение

- **Пакетный менеджер:** строго `yarn@1.22.22`. Использование `npm` или `pnpm` запрещено.
- **Node.js:** версия 20.x или 22.x LTS.

```bash
# Установка зависимостей
yarn install

# Запуск локального сервера разработки
yarn run dev

# Прогон тестового набора (50+ файлов, 380+ тестов)
yarn test
```

---

## 3. Обработка данных и протоколов

- Ручное добавление соревнований в обход пайплайна запрещено. Для импорта протоколов используется утилита сопоставления:
  ```bash
  yarn ingest-competition <path-to-draft.json>
  ```
- Для экспорта эталонных векторных протоколов соревнований в HTML и PDF:
  ```bash
  yarn export-protocol <eventId> [outDir]
  ```
- После любых изменений в данных или схемах обязательна пересборка производных индексов и проверка publish-gates:
  ```bash
  yarn run build-all-data
  ```

---

## 4. Требования к Pull Request

1. Убедитесь, что все тесты проходят без ошибок (`yarn test`).
2. Не включайте временные файлы отладки или дампы парсинга.
3. Соблюдайте соглашение по именованию коммитов (Conventional Commits: `feat:`, `fix:`, `docs:`, `refactor:`, `perf:`).
4. Запрещено добавлять трейлеры соавторства ботов (`Co-Authored-By`) в текст коммитов.

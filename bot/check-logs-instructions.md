# Как проверить логи Cloudflare Workers

## 1. Зайдите в Cloudflare Dashboard
- Откройте https://dash.cloudflare.com/
- Войдите в аккаунт
- Перейдите в "Workers & Pages"

## 2. Найдите бота
- В списке Workers найдите "coursing-stats-bot"
- Кликните на него

## 3. Откройте логи
- Перейдите на вкладку "Logs"
- Выберите "Invocations" или "Events"

## 4. Ищите наши debug сообщения
После нажатия на кнопки в боте, ищите в логах:
- `📱 Callback query received: [data]` - значит кнопка нажата и достигла Worker
- `✅ Callback query answered: [data]` - значит Worker ответил на callback
- `🏆 Ratings button pressed` - конкретная кнопка "Рейтинг"
- `📅 Calendar button pressed` - конкретная кнопка "Календарь"

## 5. Что означают разные сценарии

### Сценарий А: Нет логов вообще
**Проблема**: Telegram не отправляет webhook на Worker
**Решение**: Проблема с настройкой webhook в Telegram

### Сценарий Б: Логи есть "received" но нет "answered"  
**Проблема**: Middleware не работает
**Решение**: Код не задеплоился правильно

### Сценарий В: Логи есть и "received" и "answered"
**Проблема**: Всё работает на уровне Worker, проблема в Telegram клиенте
**Решение**: Перезапустить Telegram, очистить кэш

## 6. Real-time Tail (опционально)

Если хотите видеть логи в реальном времени:
```bash
npx wrangler tail coursing-stats-bot
```

Это покажет все логи в реальном времени когда вы нажимаете кнопки.

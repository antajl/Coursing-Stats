# RKF Tracker • Telegram Bot

Отдельный Telegram-бот для мониторинга заявок и титулов личного кабинета RKF.Online.

---

## Запланированный функционал

- **Периодический опрос:** Автоматическая проверка статусов заявок раз в час / сутки через Cloudflare Workers Cron Trigger или локальный сервис.
- **Мгновенные уведомления:** Пуш-сообщения при изменении статуса:
  - «Заявка №... на получение титула ЧРКФ изменила статус: Готов к выдаче!»
- **Личный кабинет собаковода в Telegram:**
  - Кнопка «Мои заявки» со списком активных документов и кликабельными карточками;
  - Кнопка «Отметить: забрали из РКФ»;
  - Просмотр этапов и истории движения заявки.
- **Привязка аккаунта:**
  - Безопасная авторизация по токену или логину/паролю с шифрованием в Cloudflare KV / D1.

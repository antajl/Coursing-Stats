# RKF Tracker Suite

Единое изолированное пространство инструментов для мониторинга заявок и титулов в личном кабинете RKF.Online в рамках экосистемы CoursingStats.

---

## Структура подпроекта

| Модуль | Описание | Статус |
|---|---|---|
| **`extension/`** | Автономное расширение для Chromium-браузеров (Manifest V3, 100% Client-side, zero backend) | Готово к тестированию |
| **`desktop/`** | Локальный сервис Windows и HTML-дашборд на рабочем столе (`127.0.0.1:4199`) | Работает локально |
| **`bot/`** | Выделенный Telegram-бот для уведомлений о смене статусов и личного кабинета | В проектировании |
| **`web/`** | Веб-версия дашборда для браузеров (`my.coursing-stats.ru`) | В проектировании |

---

## Изоляция от продакшена

Все файлы в папке `rkf-tracker/` изолированы от сборки и деплоя публичного сайта `coursing-stats.ru`:
1. В `.github/workflows/deploy.yml` настроен фильтр `paths-ignore: - 'rkf-tracker/**'`.
2. Локальные токены и файлы состояний (`config.json`, `state.json`, `received.json`) занесены в `.gitignore`.

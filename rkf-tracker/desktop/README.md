# CoursingStats • RKF Tracker Desktop (Ветка №4)

Нативный Windows трей-клиент и фоновый сервис мониторинга личного кабинета и реестров РКФ.

---

## Ключевые возможности

1. **Полная автономность (Zero Dependencies):**
   - Для работы у конечного пользователя не требуется установленный Node.js, Rust, Python или сторонние среды.
   - Использует стандартные встроенные компоненты Windows (WebView2 / Microsoft Edge App-mode, .NET Framework 4.8).

2. **Системный трей Windows:**
   - Приложение работает в области уведомлений (рядом с системными часами) с иконкой CoursingStats.
   - Сворачивание при закрытии окна (процесс не прерывается).
   - Контекстное меню по правому клику:
     - **Открыть дашборд** (или двойной клик по иконке)
     - **Проверить сейчас**
     - **Автозагрузка с Windows** (переключатель в реестре HKCU)
     - **Настройки** (быстрое открытие config.json)
     - **Выход**

3. **Фоновый опрос и нативные уведомления:**
   - Фоновый таймер (раз в 60 минут) с нулевой нагрузкой на процессор (0.0% CPU в режиме ожидания).
   - Вычисление diff статусов заявок: при смене статуса (например, «Изготовлен и готов к выдаче») всплывает нативный BalloonTip Windows.
   - Клик по уведомлению мгновенно открывает дашборд.

4. **Интерфейс приложения:**
   - Открывает портал `rkf-tracker/web` в безрамочном нативном режиме Microsoft Edge App-mode без адресных строк и вкладок браузера.

---

## Архитектура файлов

| Файл | Описание | Строк |
|---|---|---|
| `Program.cs` | Точка входа, системный трей NotifyIcon, меню, обработка кликов и таймера | < 150 |
| `LocalServer.cs` | Встроенный HttpListener (раздача статики web/ + CORS-прокси к API РКФ) | < 190 |
| `Poller.cs` | Модуль HTTPS-опроса API РКФ, парсинг ленты, diff статусов, сохранение state.json | < 190 |
| `AutostartHelper.cs` | Управление автозагрузкой через реестр Windows (`HKCU\...\Run`) | < 60 |
| `app.ico` | Иконка приложения в трее и проводнике (стиль CoursingStats) | - |
| `build.ps1` / `build.bat` | Быстрая компиляция переносимого `RkfTracker.exe` через встроенный `csc.exe` | < 50 |

---

## Сборка и запуск

Сборка из исходников (занимает менее 1 секунды):

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Или через командную строку Windows:

```cmd
build.bat
```

Результат сборки помещается в `rkf-tracker/desktop/dist/`:
- `RkfTracker.exe` (портативный бинарник ~44 КБ)
- `web/` (веб-интерфейс дашборда)
- `app.ico`
- `config.example.json`

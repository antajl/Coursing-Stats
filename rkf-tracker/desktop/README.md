# CoursingStats • RKF Tracker Desktop (Ветка №4)

Монолитный нативный Windows трей-клиент и фоновый сервис мониторинга личного кабинета и реестров РКФ.

---

## Ключевые возможности

1. **Монолитное нативное приложение (Embedded WebView2 Host):**
   - Единый процесс `RkfTracker.exe` (вместо запуска внешнего процесса Edge).
   - Внутри нативной формы Windows встроен официальный компонент `Microsoft.Web.WebView2`.
   - Полностью вырезан браузерный хром: отключены контекстные меню Chromium, служебные хоткеи (F5, F12, Ctrl+R, Ctrl+P) и панель статуса ссылок.
   - Любые внешние ссылки (на сайт или реестры) автоматически открываются в системном браузере пользователя по умолчанию.
   - Не требуется установка Node.js, Rust или сторонних сред на ПК пользователя.

2. **Системный трей Windows и нативный жизненный цикл:**
   - Приложение работает в области уведомлений (рядом с часами) с иконкой CoursingStats.
   - Нажатие на крестик `[X]` не завершает процесс, а мгновенно скрывает окно (`Hide()`).
   - Двойной клик по иконке у часов или выбор «Открыть дашборд» моментально возвращает окно на экран без перезагрузки.
   - Контекстное меню по правому клику:
     - **Открыть дашборд** (жирный шрифт, действие по умолчанию)
     - **Проверить сейчас** (принудительный опрос API РКФ)
     - **Автозагрузка с Windows** (переключатель в реестре HKCU)
     - **Настройки** (быстрое открытие config.json)
     - **Выход** (полное освобождение ресурсов и закрытие)

3. **Фоновый опрос и нативные уведомления:**
   - Фоновый таймер раз в 60 минут с нулевой нагрузкой на процессор (0.0% CPU в ожидании).
   - Дедупликация событий (`seenBarcodes`) исключает ложные всплывающие окна по архивным/отклоненным заявкам.
   - Нативный тост Windows (BalloonTip) всплывает только при реальной смене статуса активной заявки. Клик по тосту разворачивает окно.

4. **Геометрия окна:**
   - Стартовый размер: `1100 × 720` px.
   - Минимальный размер: `850 × 550` px (контент никогда не сминается).
   - Свободное растягивание и разворачивание на весь экран.

## Архитектура файлов

| Файл | Описание | Строк |
|---|---|---|
| `Program.cs` | Точка входа, Mutex, создание формы MainWindow, трей NotifyIcon, меню | < 150 |
| `MainWindow.cs` | Нативная форма Windows Forms со встроенным контролом WebView2 | < 100 |
| `LocalServer.cs` | Встроенный HttpListener (раздача статики web/ + CORS-прокси к API РКФ) | < 200 |
| `Poller.cs` | Модуль HTTPS-опроса API РКФ, дедупликация ленты, diff статусов | < 200 |
| `AutostartHelper.cs` | Управление автозагрузкой через реестр Windows (`HKCU\...\Run`) | < 60 |
| `app.ico` | Иконка приложения в трее и проводнике (стиль CoursingStats) | - |
| `build.ps1` / `build.bat` | Быстрая компиляция переносимого `RkfTracker.exe` через встроенный `csc.exe` | < 75 |

---

## Сборка и запуск

Сборка из исходников (занимает ~1 секунду):

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Или через командную строку Windows:

```cmd
build.bat
```

Результат сборки помещается в `rkf-tracker/desktop/dist/`:
- `RkfTracker.exe` (портативный бинарник ~50 КБ)
- `Microsoft.Web.WebView2.Core.dll` (~600 КБ)
- `Microsoft.Web.WebView2.WinForms.dll` (~38 КБ)
- `WebView2Loader.dll` (~165 КБ)
- `web/` (веб-интерфейс дашборда)
- `app.ico`
- `config.example.json`

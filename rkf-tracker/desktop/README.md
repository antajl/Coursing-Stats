# CoursingStats • RKF Tracker Desktop Service

Локальный демон и HTML-дашборд для мониторинга заявок РКФ прямо с рабочего стола Windows.

---

## Архитектура

- **`render.cjs`** — генератор компактного HTML-дашборда в дизайн-системе CoursingStats (Old Money палитра, touch targets ≥ 44px, zero emojis).
- **`update.cjs`** — модуль безопасного опроса API RKF.Online (агрегация ленты уведомлений + реестров заявок для извлечения кличек собак и названий титулов).
- **`server.cjs`** — легковесный локальный HTTP-сервер на порту 4199 (`127.0.0.1:4199`) для обработки кликов кнопки «Обновить» и чекбоксов «Забрали» из браузера без перезагрузки страницы.
- **`config.example.json`** — шаблон конфигурации (`config.json` исключен из git в `.gitignore` для безопасности).

# RKF Tracker • Web Dashboard (`coursing-stats.ru/tracker/`)

Веб-приложение для мониторинга заявок и титулов РКФ.

---

## Архитектура

- **Frontend:** Легковесный React / Vite интерфейс в эстетике Old Money (zero emojis, sand/camel/charcoal).
- **Авторизация:** Вход в личный кабинет РКФ с поддержкой прямого подключения к API.
- **Интеграция:** Синхронизация статусов с Chrome-расширением и Telegram-ботом.

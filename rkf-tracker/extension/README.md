# CoursingStats • Заявки и соревнования РКФ (Chrome Extension)

Автономное расширение для браузера (Google Chrome, Яндекс Браузер, Brave, Microsoft Edge) на базе **Manifest V3** для мониторинга заявок в личном кабинете [rkf.online](https://rkf.online) и отслеживания утверждения соревнований РКФ.

---

## Возможности

### Раздел 1: Заявки на титулы (RKF.Online)
- **Автоматическая авторизация:** Расширение само подхватывает активную сессию из открытой вкладки `rkf.online` (через безопасный `content_script`). Не нужно вводить логин и пароль вручную.
- **Полная карточка заявки:**
  - Штрихкод и прямая ссылка на заявку в РКФ;
  - Название титула / документа (выжимка из реестра);
  - Кличка собаки и номер родословной;
  - Текущий статус с цветовым маркером (зеленый — готов к выдаче, синий — в обработке, красный — отклонен, серый — архив);
  - Индикатор даты последнего обновления.
- **Хронология рассмотрения:** Клик по строке заявки плавно раскрывает историю этапов с точными датами.
- **Отметка «Забрали из РКФ»:** Чекбокс для готовых документов. Сохраняется локально в памяти браузера (`chrome.storage.local`).
- **Фильтрация и поиск:** Вкладки (Все / В обработке / Готовы к выдаче / Забрали) и мгновенный поиск по кличке собаки, названию титула или штрихкоду.
- **Полноэкранный режим:** Кнопка разворачивания трекера в отдельную вкладку браузера для комфортного просмотра на больших экранах.
- **Защита от спама:** Кулдаун 60 секунд на кнопку «Обновить» с таймером обратного отсчета.

### Раздел 2: Соревнования и испытания РКФ
- **Мониторинг утверждения:** Просмотр официального календаря мероприятий РКФ (сезоны 2027 и 2026).
- **Статусы согласования:** Наглядное разделение на «Утверждено РКФ» и «На согласовании».
- **Мгновенный поиск:** Фильтрация по городу, региону, клубу-организатору, дисциплине (курсинг, рейсинг, бега) и судейской бригаде.
- **Персональный мониторинг:** Добавление интересующих состязаний в «Отслеживаемые» в один клик с локальным сохранением в браузере.
- **Работа без авторизации:** Доступен сразу после установки без необходимости входа в личный кабинет РКФ.

## Безопасность и приватность

- **100% Client-side:** Все запросы отправляются напрямую из браузера на официальные эндпоинты РКФ и CDN `coursing-stats.ru`.
- **Zero Backend:** У расширения нет промежуточных серверов, аналитики или сторонних баз данных.
- **Изоляция данных:** Учетные данные, токены и список отслеживаемых мероприятий хранятся исключительно в защищенном локальном хранилище браузера (`chrome.storage.local`).

## Установка за 3 шага (Режим разработчика)

1. **Распакуйте архив:** Скачайте и распакуйте файл `coursingstats-tracker.zip` в любую постоянную папку на компьютере (например, `D:\Apps\CoursingStatsTracker`).
2. **Включите режим разработчика:** В браузере откройте страницу расширений:
   - Chrome / Brave: `chrome://extensions/`
   - Яндекс Браузер: `browser://extensions/`
   - Edge: `edge://extensions/`  
   В правом верхнем углу включите тумблер **«Режим разработчика»** (*Developer mode*).
3. **Загрузите расширение:** В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите распакованную папку. Закрепите значок на панели браузера (значок пазла → булавка).

## Сборка релизного архива

Для сборки чистого zip-архива дистрибутива выполните команду:

```bash
yarn pack-extension
```

Скрипт формирует чистый архив `coursingstats-tracker.zip` (без служебных файлов git и readme), готовый к публикации на GitHub Releases или установке пользователями.

# RKF Tracker Suite • Стратегический Roadmap

> Единый путеводитель по направлению мониторинга личного кабинета и реестров РКФ в рамках экосистемы CoursingStats.  
> При старте нового чата по трекеру агент обязан изучить этот документ.

---

## 1. Концепция и цели направления

Направление **RKF Tracker** решает две ключевые боли российских собаководов, заводчиков и организаторов:
1. **Персональный трекинг заявок:** мониторинг изготовления чемпионских дипломов, племенных сертификатов и выписок на `rkf.online` с мгновенным оповещением о статусе «Готово к выдаче».
2. **Мониторинг соревнований и испытаний:** отслеживание официального утверждения мероприятий РКФ (по реестрам `info.rkf.online`) без необходимости вручную скачивать и вычитывать таблицы Excel.

## 2. Архитектурная карта подпроекта

```
d:\Site\CoursingStats\rkf-tracker\
├── web/            # Портал my.coursing-stats.ru + PWA (установка на ПК в 1 клик)
├── bot/            # Telegram-бот @coursing_stats_tracker_bot (push-уведомления)
├── extension/      # Chrome-расширение Manifest V3 (автоподхват сессии из вкладки)
├── desktop/        # Локальный трей-клиент / CLI прототип
├── ROADMAP.md      # Этот стратегический роадмап (Single Source of Truth)
└── README.md       # Краткое введение и правила изоляции
```

### Незыблемые правила разработки (Invariants)
- **Строго ZERO эмодзи** во всех интерфейсах, коде, коммитах и документации.
- **File-Budget (< 250–300 строк):** при приближении файла к 250 строкам — немедленная модульная декомпозиция.
- **Изоляция от основного продакшена:** папка `rkf-tracker/` не влияет на сборку `coursing-stats.ru` (в `.github/workflows/deploy.yml` настроен `paths-ignore: - 'rkf-tracker/**'`).
- **Безопасность учетных данных:** токены и файлы окружения (`.env`, `config.json`) строго в `.gitignore`.

## 3. Пять ключевых направлений (Tracks)

### Track 1: Портал `my.coursing-stats.ru` (Web & PWA)
- **Статус:** Каркас готов, Old Money стиль сайта внедрен, локальный сервер `yarn dev:my` на порту 4200.
- **Что сделано:**
  - Полный дизайн в стиле CoursingStats: навбар с логотипом, хлебные крошки, сводка из 4 KPI-карточек, футер, тёплый фон с микрозерном (`grain-overlay`).
  - Горизонтальная таблица заявок, бейджи статусов, аккордеон хронологии, эффект «матовой пленки» для забранных документов.
  - Модульная архитектура: `shell.css`, `dashboard.css`, `cards.css`, `modal.css`, `app.js`, `render.js`, `formatters.js`, `mockData.js`.
- **Что предстоит сделать:**
  - Подключить `manifest.webmanifest` и `sw.js` (Service Worker) для превращения сайта в PWA с установкой на рабочий стол Windows/Android в один клик.
  - Реализовать кнопку «Установить на ПК» (обработчик `beforeinstallprompt`).
  - Настроить безопасную работу с токенами и привязку сессии к профилю собаковода.

### Track 2: Telegram-бот (`@coursing_stats_tracker_bot`)
- **Статус:** Токен получен и изолирован в `rkf-tracker/bot/.env`. Модуль готов к разработке.
- **Целевая аудитория:** 90% мобильных пользователей (уведомления в карман на выставках и в дороге).
- **Что предстоит сделать:**
  - Базовые команды: `/start`, `/help`, `/status`, `/settings`.
  - Авторизация пользователя: ввод токена или связка через защищенный веб-вход.
  - Фоновый воркер (Cron/Alarm): периодический опрос API РКФ (раз в 1–4 часа) с вычислением diff статусов.
  - Шаблоны уведомлений: мгновенный алерт при смене статуса (например, «Изготовлено и готово к выдаче»).
  - Кнопка «Мои заявки» внутри чата — открытие дашборда `my.coursing-stats.ru` как **Telegram Mini App** (без выхода из мессенджера).

### Track 3: Расширение для Chrome (CoursingStats Tracker)
- **Статус:** Версия 1.0 полностью собрана и оттестирована в `rkf-tracker/extension/`.
- **Особенности:**
  - 100% Client-side на Manifest V3 (zero backend, нулевые риски для приватности).
  - Уникальное преимущество: автоматический захват Bearer-токена из активной вкладки `rkf.online` через `content_script`.
  - Фиксированный попап 780px, синтез звука через Web Audio API, нативные алерты Windows с кнопкой «Тест».
- **Что предстоит сделать:**
  - Подготовить чистый релизный ZIP-архив в открытом коде на GitHub Releases.
  - На странице сайта сделать иллюстрированную инструкцию из 3 шагов для установки через Developer Mode (без сомнительных `.bat` скриптов).

### Track 4: Мониторинг соревнований и состязаний РКФ (info.rkf.online)
- **Контекст:** Реализация запроса из диалога [RKF Request Tracking Extension](conversation://6cd80b47-70b9-4bb2-b685-d530345a9741).
- **Источник данных:** Страница [info.rkf.online: Тестирования, испытания и состязания](https://info.rkf.online/article/fb2b53ca-bdf2-5e35-bea2-2e973592e2d7).
- **Проблема:** РКФ публикует статусы согласования мероприятий в виде периодически обновляемых реестров Excel (`.xlsx`). Организаторам и участникам приходится вручную выкачивать многомегабайтные таблицы и искать свои строки.
- **Архитектура решения:**
  - **In-Memory Streaming:** файл Excel не скачивается в папку «Загрузки» пользователя. Бэкенд или браузерный скрипт загружает поток байтов в `ArrayBuffer` оперативной памяти и парсит его с помощью легковесной библиотеки (`xlsx` / `exceljs`).
  - **Система подписок:** собаковод или клуб указывает город, дисциплину (курсинг, ОКД, аджилити и т.д.) или номер заявки.
  - **Автоматический трекинг утверждения:** при появлении отметки «Утверждено» бот и веб-кабинет присылают уведомление:  
    *«Состязание [Название] в г. [Город] на дату [Дата] официально утверждено РКФ! Номер в календаре: ...»*.

### Track 5: Единый хаб данных и авторизации (Data Hub)
- **Задача:** Бесшовная синхронизация между Web, Bot и Extension.
- **Функции:**
  - Синхронизация списка отметок «Забрали» (`is-collected`), чтобы забранный диплом не всплывал повторно в уведомлениях.
  - Единая библиотека нормализации кличек собак (`formatDogName`) и расшифровки аббревиатур РКФ (`formatDocTitle`).

## 4. Как вести разработку в новых чатах

Если вы открываете новый диалог для работы над функционалом РКФ-трекера:
1. **Назовите целевой трек:** например, *«Работаем над Track 1 (PWA)»* или *«Делаем Track 4 (парсер info.rkf.online)»*.
2. **Агент мгновенно обращается к:** `d:\Site\CoursingStats\rkf-tracker\ROADMAP.md` и `docs/invariants/ops-deploy.md`.
3. **Все изменения коммитятся локально** по стандарту Conventional Commits без автоматического `git push`.

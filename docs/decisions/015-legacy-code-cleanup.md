# ADR-015 — Удаление устаревшего кода и исторических артефактов (Archive, Turso, Elo)

## Контекст

В ходе анализа монолитности кодовой базы были обнаружены многотысячные файлы и каталоги, представляющие собой мёртвый код (dead code), накопленный за время эволюции проекта:

1. **`backend/scripts/import/archive/` (21 файл, ~7 500 строк):**
   Исторические генераторы черновиков соревнований 2021–2022 годов (`prepare-kubok-draft.ts`, `prepare-monobreed-draft.ts`, `prepare-ch-rkf-draft.ts` и серия скриптов Python). В этих файлах прямо в TypeScript/Python были зашиты многотысячные сырые массивы результатов. После однократной генерации JSON-файлов турниров в `data/v1/competitions/` скрипты перестали использоваться.
2. **`backend/scripts/turso/` (9 файлов):**
   Утилиты синхронизации и обслуживания облачной БД Turso. Turso была полностью удалена из архитектуры проекта в пользу статической отдачи 51+ тыс. сжатых gzip-протоколов из Yandex Object Storage (S3 CDN).
3. **`backend/scripts/elo/` (4 файла) и команды `elo:*` в `package.json`:**
   Экспериментальный расчёт рейтинга Elo для курсинга борзых. Рейтинг Elo был официально исключён из сайта и пайплайна в пользу олимпийского каскада (золотые медали → standingScore → очки CS v2), однако неиспользуемые скрипты расчёта и команды запуска оставались в проекте.
4. **`backend/scripts/import-archive/`:**
   Устаревшая дублирующая папка с копией скрипта импорта.

## Решение

1. **Удалить неиспользуемые файлы и каталоги:**
   - `backend/scripts/import/archive/`
   - `backend/scripts/turso/`
   - `backend/scripts/elo/`
   - `backend/scripts/import-archive/`
2. **Очистить `package.json`:**
   Удалить мёртвые команды `elo:extract`, `elo:generate`, `elo:verify`, `elo:recalibrate`, `elo:build`.
3. **Зафиксировать исторический контекст:**
   Все исходные реализации и ранние черновики сохранены в истории коммитов Git. Единым источником правды для соревнований и выставок остаётся `data/v1/`, а для ввода новых состязаний — стандартный пайплайн `yarn ingest-competition`.

## Последствия

- Освобождено более 9 000 строк мёртвого кода и 35 файлов.
- Исключены ложные срабатывания при поиске по проекту (`grep`, IDE).
- Устранена путаница между устаревшими моделями ранжирования/хранения и актуальной архитектурой S3 CDN.

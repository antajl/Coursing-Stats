# 16 — Protocol Template (HTML / PDF)

Официальный эталонный стандарт вёрстки и оцифровки протоколов соревнований по курсингу (РКФ / ProCoursing).  
Все протоколы в проекте приводятся к этому единому вектору.

---

## 0. Принцип первичности оригиналов (Источник правды)

1. **Оригинал (первичные фото, сканы секретариата, каталог турнира) — высший источник правды.**
2. Сырые фотографии или сканы (`1.png`...`N.png`) оцифровываются и оформляются в данный эталонный векторный формат (`protocol_vector.html` / `protocol_vector.pdf`).
3. Структурированные данные состязания (`data/v1/competitions/*.json`) для сайта и Telegram-бота **сверяются и валидируются по этому эталону**, гарантируя, что ни один участник, неявка (DNS), дисквалификация или балл не будут утеряны.
4. В календаре турниров в поле `results_pdf_url` публикуется ссылка именно на чистовой векторный PDF высокого разрешения, а оригинальные исходные фото сохраняются в папке на Google Диске как архивное подтверждение.

---

## 1. Концепция: HTML vs PDF

* **HTML — основной интерактивный формат:**  
  Вёрстка на 100% ширины экрана (`width: 100%; margin: 0; padding: 0;`).  
  Крупный комфортный шрифт для мониторов FHD/2K/4K (`font-size: 11pt;` база, ячейки `10.5pt;`, заголовок турнира `14pt;`, заголовки породных групп `11.5pt;`).  
  Колонка «Кличка» занимает ~33% ширины таблицы, благодаря чему полные клички свободно размещаются ровно в 1–2 строки (русское имя / английское имя) без неестественных переносов отдельных слов.  
  Чистый аутентичный документ без плавающих кнопок и посторонних элементов интерфейса.

* **PDF — печатная копия:**  
  Формат страницы: `@page { size: A4 landscape; margin: 1.5mm; }`.  
  Через `@media print` применяется оптимизированное масштабирование (`8.5pt` ячейки, `2.2px` паддинги), за счёт чего таблица задействует более **98% ширины и 96% высоты листа А4 landscape** без обрезки строк и без лишних белых полей.  
  Шапка таблицы НЕ дублируется на последующих страницах (таблица естественно перетекает между страницами).

---

## 2. Структура заголовка (Header)

На странице 1 протокол начинается **строго с единого главного названия турнира**:
```html
<tr class="top-title-row">
  <td colspan="25">Чемпионат РКФ по курсингу борзых, 10-11.10.2026 (Московская область, Раменское, д. Донино)</td>
</tr>
```
> [!IMPORTANT]
> Подзаголовки («Полные результаты состязания») и строки примечаний под названием турнира **не используются**. Сразу под строкой названия турнира идёт шапка колонок таблицы (`col-header` и `sub-col-header`).

---

## 3. Разделительные полосы ячеек (3D Beveled Borders)

Фирменный стиль протоколов ProCoursing / Access реализуется через раздельные границы ячеек с рельефной тенью:

```css
table.protocol-table {
  width: 100%;
  border-collapse: separate;
  border-spacing: 1.5px;
  background-color: #ffffff;
}
th, td {
  border-top: 1px solid #4c4c4c;    /* тёмно-серый верх */
  border-left: 1px solid #4c4c4c;   /* тёмно-серый левый край */
  border-right: 1px solid #b2b2b2;  /* светло-серый правый край */
  border-bottom: 1px solid #b2b2b2; /* светло-серый низ */
  background-color: #ffffff;
  padding: 4px 3px;
  text-align: center;
  vertical-align: middle;
  font-size: 10.5pt;
  font-weight: normal;
}
```

## 4. Типографика и баланс жирности (Font Weight)

* **Обычный шрифт (`font-weight: normal;`, `ArialMT`):**
  * Разделительные полосы породных групп (`Малая итальянская борзая_Стандартный_Кобели`);
  * Заголовки колонок (`Место`, `№`, `Порода`, `Класс`, `Пол`, `Кличка` и т.д.);
  * Судейские критерии (`Ман.`, `Резв.`, `Вын.`, `Прес.`, `Энт.`, `Сум.`);
  * Места участников и каталожные номера;
  * Судейские оценки, суммы забегов и итоговые баллы;
  * Квалификации и титулы.
* **Полужирный шрифт (`font-weight: bold;`):**
  * Строго только заглавная строка турнира (`tr.top-title-row td`).

```html
  <col style="width: 2.4%;">  <!-- Забег 1 -->
  <col style="width: 1.6%;">  <!-- Ман. 1 -->
  <col style="width: 1.6%;">  <!-- Резв. 1 -->
  <col style="width: 1.6%;">  <!-- Вын. 1 -->
  <col style="width: 1.6%;">  <!-- Прес. 1 -->
  <col style="width: 1.6%;">  <!-- Энт. 1 -->
  <col style="width: 1.6%;">  <!-- Сум. 1 -->
  <col style="width: 2.6%;">  <!-- Сумма Забега 1 -->
  <col style="width: 2.4%;">  <!-- Забег 2 -->
  <col style="width: 1.6%;">  <!-- Ман. 2 -->
  <col style="width: 1.6%;">  <!-- Резв. 2 -->
  <col style="width: 1.6%;">  <!-- Вын. 2 -->
  <col style="width: 1.6%;">  <!-- Прес. 2 -->
  <col style="width: 1.6%;">  <!-- Энт. 2 -->
  <col style="width: 1.6%;">  <!-- Сум. 2 -->

  <col style="width: 2.2%;">  <!-- СС -->
  <col style="width: 10.0%;"> <!-- Титул / Квалификация -->

```

### Б. Бега борзых / Racing (Сетка из 18 колонок, забеги 1–3, время/скорость, сумма 100%)

```html
<colgroup>
  <col style="width: 3.0%;">  <!-- Место -->
  <col style="width: 2.5%;">  <!-- № каталожный -->
  <col style="width: 9.5%;">  <!-- Порода -->
  <col style="width: 7.5%;">  <!-- Класс -->
  <col style="width: 3.8%;">  <!-- Пол -->
  <col style="width: 21.7%;"> <!-- Кличка -->
  <col style="width: 4.0%;">  <!-- Дистанция (м) -->
  <col style="width: 3.5%;">  <!-- Забег 1 -->
  <col style="width: 3.0%;">  <!-- Попона 1 (1 красная, 2 синяя, 3 белая, 4 чёрная) -->
  <col style="width: 7.0%;">  <!-- Время 1 / Скорость (время с, м/с, км/ч) -->
  <col style="width: 3.5%;">  <!-- Забег 2 -->
  <col style="width: 3.0%;">  <!-- Попона 2 -->
  <col style="width: 7.0%;">  <!-- Время 2 / Скорость -->
  <col style="width: 3.5%;">  <!-- Забег 3 -->
  <col style="width: 3.0%;">  <!-- Попона 3 -->
  <col style="width: 7.0%;">  <!-- Время 3 / Скорость -->
  <col style="width: 2.3%;">  <!-- СС -->
  <col style="width: 5.2%;">  <!-- Титул -->
</colgroup>
```
* **Каждая собака занимает строго 1 строку.**
* **Цвета попон FCI/РКФ:**
  * 1 = Красная (`#ff0000`, текст `#ffffff`)
  * 2 = Синяя (`#00a2e8`, текст `#000000`)
  * 3 = Белая (`#ffffff`, текст `#000000`, рамка)
  * 4 = Чёрная (`#000000`, текст `#ffffff`)
* **Ячейка «Время / Скорость»:** содержит 3 строки (время в секундах `32.74 с`, метры в секунду `10.69 м/с`, километры в час `38.485 км/ч`).
* **Неявившиеся участники:** секция `Неявившиеся участники` с серой заливкой `#c0c0c0` и `colspan="12"` со статусом `Неявка`.

## 6. Геометрия строк и номера забегов (Rowspan Rules)

### А. Стандартный участник (2 строки)
* **Ячейка номера забега (попоны):** объединяет обе строки одного забега через `rowspan="2"`:
  ```html
  <td rowspan="2" style="background-color: #ff0000 !important; color: #ffffff; font-style: italic;">119</td>
  ```
  Цвета попон:
  * Красная: `background-color: #ff0000; color: #ffffff; font-style: italic;`
  * Белая: `background-color: #ffffff; color: #000000; font-style: italic;`
* **Строка 1:**
  * Колонки 1–6 (`rowspan="2"`)
  * Номер Забега 1 (`rowspan="2"`)
  * Оценки Судьи 1 Забега 1 (6 ячеек)
  * Сумма Забега 1 (`rowspan="2"`)
  * Номер Забега 2 (`rowspan="2"`)
  * Оценки Судьи 1 Забега 2 (6 ячеек)
  * Сумма Забега 2 (`rowspan="2"`)
  * Общая сумма (`rowspan="2"`)
  * СС (`rowspan="2"`)
  * Титул (`rowspan="2"`)
* **Строка 2:**
  * Строго только 12 ячеек оценок:
    * Оценки Судьи 2 Забега 1 (6 ячеек)
    * Оценки Судьи 2 Забега 2 (6 ячеек)
  * Никаких пустых ячеек в начале или под номерами забегов.

### Б. Снятие / Дисквалификация в Забеге 1 (1 строка)
* 1 строка: колонки 1–6 (без rowspan) + номер забега 1 + объединение остальных колонок (`colspan="18"`) с центрированным курсивным текстом причины (например, `Снятие (Агрессия, нападение на напарника по забегу)`).

### В. Отстранение во 2-м круге (2 строки)
* Строка 1: первый забег как обычно, во втором забеге номер попоны с `rowspan="2"`, судейские оценки и сумма объединяются (`colspan="7" rowspan="2"`) с текстом причины.
* Строка 2: содержит только 6 ячеек оценок Судьи 2 для Забега 1.

### Г. Неприбывшие участники (DNS, 1 строка)
* В конце протокола создаётся отдельная секция с заголовком `Неприбывшие участники`.
* Все ячейки строки получают серую заливку (`background-color: #c0c0c0 !important;`).
* Колонка «Место» пустая, колонки 2–6 содержат номер, породу, класс, пол и кличку собаки, судейская часть объединяется (`colspan="19"`) со статусом `Неявка`.

## 7. Команда генерации (CLI)

Для любого состязания протокол генерируется одной командой:

```bash
# По ID турнира:
yarn export-protocol 2022003

# По пути к файлу и с указанием выходной папки:
yarn export-protocol data/v1/competitions/2026/10-октябрь/2022003-чркф-по-курсингу-борзых.json "C:\Users\Antal\Documents\Google.Disk\Competitions\..."
```

Скрипт автоматически:
1. Вычисляет состав породных групп и распознаёт смешанные классы (`Микс`);
2. Форматирует клички (RU / EN в 1–2 строки);
3. Генерирует эталонный `protocol_vector.html` со 100% сеткой;
4. Компилирует векторный `protocol_vector.pdf` через Microsoft Edge headless без разрывов строк и полей.

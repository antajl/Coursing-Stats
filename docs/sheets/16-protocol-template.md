# 16 — Protocol Template (HTML / PDF)

Стандарт вёрстки официальных протоколов соревнований по курсингу (РКФ / ProCoursing).

---

## 1. Концепция: HTML vs PDF

* **HTML — основной эталонный формат:**  
  Вёрстка на 100% ширины страницы (`width: 100%; margin: 0; padding: 0;`).
  Колонка «Кличка» получает максимальный приоритет по ширине (~29%), благодаря чему клички размещаются ровно в 1–2 строки (русское имя / английское имя) без неестественных переносов отдельных слов.
  Чистый аутентичный документ без плавающих кнопок и лишнего UI.
* **PDF — печатная копия:**  
  Формат `@page { size: A4 landscape; margin: 6mm 4mm; }`.
  Шапка таблицы НЕ дублируется на страницах 2–5, документ естественно перетекает между страницами.

---

## 2. Разделительные полосы (3D Beveled Borders)

Фирменный стиль протоколов ProCoursing / Access реализуется через раздельные границы ячеек с рельефной тенью:

```css
table.protocol-table {
  width: 100%;
  border-collapse: separate;
  border-spacing: 1.5px;
  background-color: #ffffff;
}
th, td {
  border-top: 1px solid #4c4c4c;    /* тёмно-серый верх */
  border-left: 1px solid #4c4c4c;   /* тёмно-серый левый край */
  border-right: 1px solid #b2b2b2;  /* светло-серый правый край */
  border-bottom: 1px solid #b2b2b2; /* светло-серый низ */
  background-color: #ffffff;
}
```

Между ячейками образуется чистый белый зазор в 1.5px, а каждая ячейка получает аккуратную визуальную глубину без монотонных сплошных линий.

---

## 3. Типографика и баланс жирности (Font Weight)

* **Обычный шрифт (`font-weight: normal;`)** используется для большинства элементов:
  * Заголовки колонок (`Место`, `№`, `Порода`, `Класс`, `Пол`, `Кличка` и т.д.);
  * Судейские критерии (`Ман.`, `Резв.`, `Вын.`, `Прес.`, `Энт.`, `Сум.`);
  * Места участников и каталожные номера;
  * Судейские оценки, промежуточные суммы и итоговые баллы;
  * Квалификации и титулы.
* **Полужирный шрифт (`font-weight: bold;`)** остаётся строго акцентным:
  * Название состязания и подзаголовок («Полные результаты состязания»);
  * Разделительные плашки породных групп (`Малая итальянская борзая_Стандартный_Кобели`).

---

## 4. Пропорции колонок таблицы

* `Место`: ~2.5%
* `№`: ~2.2%
* `Порода`: ~7.5%
* `Класс`: ~6.5%
* `Пол`: ~3.5%
* `Кличка`: **~29.0%** (максимум ширины для комфортного размещения полных кличек)
* `Забег 1`: ~2.5%
* `Оценки судей 1` (6 колонок): 6 * 1.8% = ~10.8%
* `Сумма 1`: ~2.8%
* `Забег 2`: ~2.5%
* `Оценки судей 2` (6 колонок): 6 * 1.8% = ~10.8%
* `Сумма 2`: ~2.8%
* `Общая сумма`: ~3.2%
* `СС`: ~2.2%
* `Титул`: ~11.0%

---

## 5. Цвета попон и статус участников

* **Красная попона:** `background-color: #ff0000; color: #ffffff; font-style: italic;`
* **Белая попона:** `background-color: #ffffff; color: #000000; font-style: italic;`
* **Снятие / дисквалификация:**  
  Номер забега отображается в своей попоне, остальные судейские колонки объединяются (`colspan="18"`) с центрированным курсивным текстом причины (например, `Снятие (Агрессия, нападение на напарника по забегу)`).

## 6. Генерация PDF через Microsoft Edge

```powershell
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --headless --disable-gpu --print-to-pdf="protocol.pdf" --no-pdf-header-footer "protocol.html"
```

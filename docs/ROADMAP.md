# Дорожная карта развития CoursingStats (4 ветки)

В соответствии со стратегией развития проекта, работа разделена на 4 изолированные ветки:

```
          [main]
            │
            ├── 1. feat/data-ingestion-and-dupes  (Безопасный ввод + чистка дублей)
            ├── 2. chore/docs-cleanup             (Ревизия и актуализация docs)
            ├── 3. feat/desktop-ia-design-system  (Десктоп: структура страниц, URL + UI Kit)
            └── 4. feat/mobile-redesign           (Мобильная верстка с нуля)
```

---

## Статус направлений (Все ветки объединены в `main`)

| Ветка / Направление | Фокус | Статус |
|---|---|---|
| **1. `feat/data-ingestion-and-dupes`** | Безопасный конвейер `yarn ingest-competition`, сопоставление собак, отчёт дублей | ✅ Слито в `main` |
| **2. `chore/docs-cleanup`** | Актуализация архитектуры (Yandex Cloud, CDN-only, ADRs, шпаргалки) | ✅ Слито в `main` |
| **3. `feat/desktop-ia-design-system`** | Архитектура десктопа (`?tab=`), дизайн-контракт Saluki (`14-design-system.md`) | ✅ Слито в `main` |
| **4. `feat/mobile-redesign`** | Адаптация разделов: шапки, табы, карточки, фильтры, Донино | ✅ Слито в `main` |

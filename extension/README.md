# CoursingStats • Заявки РКФ (Chrome Extension)

Автономное расширение для браузера (Google Chrome, Яндекс Браузер, Brave, Microsoft Edge) на базе **Manifest V3** для мониторинга заявок и титулов в личном кабинете [rkf.online](https://rkf.online).

---

## Возможности

- **Автоматическая авторизация:** Расширение само подхватывает активную сессию из открытой вкладки `rkf.online` (через безопасный `content_script`). Не нужно вводить логин и пароль вручную.
- **Полная карточка заявки:**
  - Штрихкод и прямая ссылка на заявку в РКФ;
  - Название титула / документа (выжимка из реестра);
  - Кличка собаки и номер родословной;
  - Текущий статус с цветовым маркером (зеленый — готов к выдаче, синий — в обработке, красный — отклонен, серый — архив);
  - Индикатор даты последнего обновления.
- **Хронология рассмотрения:** Клик по строке заявки плавно раскрывает историю этапов с точными датами.
- **Отметка «Забрали из РКФ»:** Чекбокс для готовых документов. Сохраняется локально в памяти браузера (`chrome.storage.local`).
- **Фильтрация и поиск:**
  - Вкладки: Все / В обработке / Готовы к выдаче / Забрали;
  - Мгновенный поиск по кличке собаки, названию титула или штрихкоду.
- **Полноэкранный режим:** Кнопка разворачивания трекера в отдельную вкладку браузера для комфортного просмотра на больших экранах.
- **Защита от спама:** Кулдаун 60 секунд на кнопку «Обновить» с таймером обратного отсчета.
- **Безопасность и приватность:**
  - 100% клиентская работа: все запросы идут напрямую из браузера на официальный API `rkf.online`.
  - Никакие токены, пароли или данные собак не отправляются на сторонние серверы.

## Как установить локально (Режим разработчика)

1. Откройте браузер на базе Chromium (Google Chrome, Яндекс Браузер, Brave, Edge).
2. Перейдите по адресу:
   ```text
   chrome://extensions/
   ```
   *(для Яндекс Браузера: `browser://extensions/`)*
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (*Developer mode*).
4. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
5. Выберите папку `extension` из этого репозитория (`d:\Site\CoursingStats\extension`).
6. Закрепите иконку расширения на панели браузера (значок пазла в правом верхнем углу → булавка).
7. Откройте [rkf.online](https://rkf.online) в соседней вкладке и авторизуйтесь.
8. Нажмите на значок расширения — заявки загрузятся автоматически!

## Публикация в Chrome Web Store

- **Стоимость регистрации разработчика:** разовый платеж \$5 в [Google Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole).
- **Процесс публикации:**
  1. Запаковать содержимое папки `extension/` в ZIP-архив (без вложенной корневой папки).
  2. Загрузить архив в Developer Dashboard.
  3. Заполнить описание, категорию (*Productivity* / *Продуктивность*) и загрузить 1–2 скриншота интерфейса.
  4. Модерация Google занимает от 24 до 72 часов.
